# 斐波那契数列
段落 斐波那契 接收 甲：
  如果 甲 小于 2 那么：
    返回 甲。
  结束
  返回 斐波那契(甲 减 1) 加 斐波那契(甲 减 2)。
结束

设斐为0。
当 斐 小于 10：
  打印("斐波那契(" + 转字符串(斐) + ") = " + 转字符串(斐波那契(斐)))。
  设斐为 斐 加 1。
结束

# 汉诺塔
段落 汉诺塔 接收 甲, 乙, 丙, 丁：
  如果 甲 大于 0 那么：
    汉诺塔(甲 减 1, 乙, 丙, 丁)。
    打印("移动盘子 " + 转字符串(甲) + " 从 " + 乙 + " 到 " + 丁)。
    汉诺塔(甲 减 1, 丙, 丁, 乙)。
  结束
结束

打印("汉诺塔 3 层：")。
汉诺塔(3, "A", "C", "B")。

# 冒泡排序
段落 冒泡排序 接收 甲：
  设乙为 列表长度(甲)。
  设丙为0。
  当 丙 小于 乙 减 1：
    设丁为0。
    当 丁 小于 乙 减 丙 减 1：
      如果 甲[丁] 大于 甲[丁 加 1] 那么：
        设临时为 甲[丁]。
        甲[丁] 为 甲[丁 加 1]。
        甲[丁 加 1] 为 临时。
      结束
      设丁为 丁 加 1。
    结束
    设丙为 丙 加 1。
  结束
  返回 甲。
结束

设数列为 [5, 3, 8, 1, 2]。
打印("排序前：")。
打印(数列)。
设已排序为 冒泡排序(数列)。
打印("排序后：")。
打印(已排序)。
